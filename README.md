## 💻 O que eu faço

- **Desenvolvimento Backend:** criação de aplicações e APIs utilizando Node.js, JavaScript, TypeScript e Go.
- **APIs REST:** desenvolvimento de rotas, autenticação, validação de dados, regras de negócio e integração entre serviços.
- **Banco de Dados:** modelagem, consultas e integração com PostgreSQL e MySQL.
- **Desenvolvimento Web:** conhecimentos de HTML, CSS, JavaScript e TypeScript para integração com aplicações frontend.
- **Infraestrutura:** utilização de Linux e Docker no ambiente de desenvolvimento e deploy.
- **Cloud:** estudo e utilização de serviços AWS para hospedagem e infraestrutura de aplicações.
